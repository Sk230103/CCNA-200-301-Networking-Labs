# Lab 01: Configuring Static Routes

## Overview
This lab focuses on configuring IPv4 static routes using Cisco Packet Tracer as part of CCNA 200-301 preparation.

## Objectives
- Understand how static routing works.
- Configure static routes using Cisco IOS.
- Examine router routing tables.
- Verify connectivity between remote networks.
- Practice basic routing troubleshooting.

## Tools
- Cisco Packet Tracer
- Cisco IOS CLI

## Key Commands

```text
show ip route
show ip interface brief
show running-config
ping
traceroute
```

## Lab Files
- `Day-11-Configuring-Static-Routes.pkt` — Cisco Packet Tracer lab file.

## Verification
Use the router routing tables and connectivity tests to check whether the configured routes allow communication between the required networks.

## Learning Outcome
Practice manually configuring routes and understanding how routers forward traffic to remote networks.
